# Dependabot live integration fixtures

Disposable public fixtures for [mergelog/dpb-test](https://github.com/mergelog/dpb-test).
Dependencies are intentionally outdated; these files are test inputs.

The default `control` branch owns the Dependabot configuration. Update PRs target protected `main`, or `dependency-testing` for the target-branch case.
`main` requires one approval including administrators. No real private registry credentials are stored.

Verification completed on 2026-11-14. Version-update limits are zero, security fixes are disabled, and the repository is archived to preserve evidence.
See the [verification report](https://github.com/mergelog/dpb-test/blob/docs/dependabot-guide/docs/dependabot-verification.md) for scope and results.
